# Ultimate platform implementation

Branch: `codex/ultimate-platform`, based on the working `codex/local-ultimate` release. This upgrade preserves Next.js/React, FastAPI/SQLAlchemy, the existing database, local Ollama, worker, native FFmpeg and browser edition. New capabilities belong to the localhost edition; GitHub Pages cannot run the native worker or secure OAuth callbacks.

Baseline release checks: 176 backend tests, 59 frontend checks and native/static builds passed before this upgrade. The prior release's real local acceptance and GPU measurements are in `LOCAL_ULTIMATE.md`; they do not establish performance or correctness of this new three-draft workflow.

Campaign slice: local PDF page extraction, safe UTF-8 TXT/DOCX imports and bounded optional Tesseract/Poppler OCR retain source sections. Exact title/description/on-video requirements, prohibited platforms, branding/logo/resolution and other mandatory terms survive schema validation. Contradictions remain explicit. Required hashtags retain exact spelling/order before optional tags across native generated and manual metadata; compliance rejects reordered tags and missing exact wording. OCR requires separately installed executables and is not claimed tested on a real scan yet. Semantic branding/on-video checks require actual human evidence.

Project/draft slice: persistent projects and reference profiles reuse existing sources/campaigns/jobs. Defaults are three10-second drafts, configurable6–20-second project bounds intersected with mandatory campaign bounds. Source-grounded ranking retains at most three distinct windows and explicitly reports a shortfall. Source directories are configurable; imports copy through the existing validated source importer and never move originals. Full-width fit on a source-derived blurred background preserves the entire gameplay image; optional bounded crop remains available. Reference profiles measure real cuts and sampled pixels, not copyrighted asset copying or inferred sound/font recognition.

The native studio provides draft playback, source timeline/crop/zoom/effect edits, source audio controls, metadata editing, undo/redo for timeline changes, campaign evidence entry and version-specific approve/reject. Material edits create new renders/versions. Actual-artifact evaluation fully decodes the output, samples three real frames, measures cuts and requests bounded local-model observations. Eight configurable weighted components produce separate YouTube/TikTok editorial scores with low confidence and explicit unavailable retention/audio-sync evidence. Controlled model tests confirm the artifact sampling/scoring contracts, not semantic editing quality. Supported Auto-Improve actions create a new version rather than overwriting the old output. Platform advice excludes known non-compliant drafts.
